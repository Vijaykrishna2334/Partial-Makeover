Upload Your Project to GitHub

A step-by-step guide to get your project repository online.

Prerequisites

  • You have Git installed on your computer.
  • You have a GitHub account.
  • Your project files are in a dedicated folder on your local machine.

Instructions

  1. Step 1: Initialize a Git Repository

    Open your terminal or command prompt, navigate to your project's root directory, and run the following command. This creates a new, hidden `.git` folder that will track all your changes.

    git init

  2. Step 2: Add All Files to Staging

    This command "stages" all the files in your project, preparing them for the first snapshot (commit).

    git add .

  3. Step 3: Make Your First Commit

    A commit saves the staged changes to your local repository's history. The `-m` flag lets you add a descriptive message.

    git commit -m "Initial commit"

  4. Step 4: Create a New Repository on GitHub

    Go to github.com/new. Give your repository a name (e.g., `ai-interior-designer`), choose whether it should be public or private, and click "Create repository". Do not initialize it with a README, .gitignore, or license file, as your project already has these files.

  5. Step 5: Link Your Local and Remote Repositories

    GitHub will provide you with a URL for your new repository. Copy the command below and replace `YOUR_GITHUB_REPOSITORY_URL` with that URL. This tells your local Git where to send the files.

    git remote add origin YOUR_GITHUB_REPOSITORY_URL

    Next, it's good practice to rename the default branch from `master` to `main` to align with modern standards.

    git branch -M main

  6. Step 6: Push Your Code to GitHub

    Finally, this command uploads your committed files from your local `main` branch to the `origin` (your GitHub repository).

    git push -u origin main

You're all set! Your code is now live on GitHub.
